## 📋 测试清单

### 第一阶段：配置验证（5分钟）

- [ ] 配置环境变量
  ```bash
  vim cloud_settings/.env
  # 添加：
  # RALENDAR_OAUTH_CLIENT_ID=xxx
  # RALENDAR_OAUTH_CLIENT_SECRET=yyy
  ```

- [ ] 重启服务
  ```bash
  supervisorctl restart roamio
  ```

- [ ] 验证配置生效
  ```bash
  python manage.py shell
  >>> from django.conf import settings
  >>> print(settings.RALENDAR_OAUTH_CLIENT_ID)
  ```
