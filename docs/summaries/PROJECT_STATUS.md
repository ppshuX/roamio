## 🏗️ 技术架构状态

### 前端（Vue 3）

**技术栈**：
- Vue 3 (Composition API)
- Vue Router 4
- Pinia (状态管理)
- Bootstrap 5
- Axios

**代码结构**：
```
web/src/
├── api/                     # API 调用层
├── components/              # 通用组件
│   ├── comments/           # 评论组件
│   ├── editor/             # 编辑器组件
│   └── UserProfilePopover.vue  ⭐ 新增
├── views/                   # 页面组件
│   ├── auth/               # 认证页面
│   ├── user-center/        # 个人中心
│   └── ...
├── stores/                  # 状态管理
├── router/                  # 路由配置
└── config/                  # 配置文件
```

**构建产物**：
```
web/dist/                    # 前端构建产物（提交到 Git）
├── index.html
├── assets/
│   ├── js/                 # 代码分割后的 JS 文件
│   └── css/                # 样式文件
├── images/                 # 图片资源
└── music/                  # 音乐资源
```

**部署方式**：
- 本地构建 → 提交 `dist/` → 服务器 `git pull` → Nginx 直接服务

### 后端（Django REST）

**技术栈**：
- Django 4.2
- Django REST Framework
- django-cors-headers
- django-filter
- Pillow (图片处理)

**代码结构**：
```
backend/
├── models/                  # 数据模型
│   ├── user_profile.py     # 用户配置（新增 birthday 字段）⭐
│   ├── trip.py             # 旅行计划
│   ├── comment.py          # 评论
│   └── ...
├── serializers/             # 序列化器
│   ├── user_serializer.py  # 用户序列化（支持 birthday）⭐
│   └── ...
├── api/
│   └── viewsets/           # API 视图集
│       ├── user_viewset.py # 新增 profile 端点 ⭐
│       └── ...
├── utils/                   # 工具函数
│   ├── email_service.py    # 邮件服务
│   ├── qq_oauth.py         # QQ 登录
│   └── tencent_cos.py      # 腾讯云 COS
└── views/                   # 视图（兼容旧路由）
```

**API 端点**：
```
/api/v1/users/                          # 用户列表
/api/v1/users/{id}/profile/             # 用户公开资料 ⭐ 新增
/api/v1/trips/                          # 旅行列表
/api/v1/trip-plans/                     # 旅行计划
/api/v1/comments/                       # 评论
/api/v1/auth/                           # 认证
```

### 部署架构

**Nginx 配置**：
```nginx
location /              { root /home/acs/roamio/web/dist; }  # 前端
location /api           { uwsgi_pass 127.0.0.1:8000; }       # API
location /admin         { uwsgi_pass 127.0.0.1:8000; }       # Admin
location /admin-static  { alias /home/acs/roamio/staticfiles/; }
location /wss           { proxy_pass http://127.0.0.1:5015; } # WebSocket
```

**部署流程**：
```bash
# 本地
npm run build
git add -A
git commit -m "feat: xxx"
git push

# 服务器
git pull
pkill -9 uwsgi
uwsgi --ini cloud_settings/uwsgi.ini --daemonize uwsgi.log
```
