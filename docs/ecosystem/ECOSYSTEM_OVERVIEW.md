## 🔷 核心产品：Roamio

### 定位
**旅行记录与分享平台** - 生态系统的主轴

### 核心功能
- 🗺️ 旅行计划制定与管理
- 📍 旅行打卡与实时记录
- 💬 内容分享与社交互动
- 👤 用户中心与资料管理

### 技术栈
- **后端**: Django 4.2 + Django REST Framework
- **前端**: Vue 3 + Pinia + Vue Router
- **数据库**: SQLite (开发) / MySQL (生产)
- **部署**: Nginx + uWSGI

### 当前状态
- ✅ 已上线运行
- ✅ 完整的前后端分离架构
- ✅ 真实用户使用中

## 📅 子产品 1：Ralendar

### 定位
**日历助手** - Roamio 生态的时间管理工具

### 核心功能
- 📆 多日历管理
- 📝 事件创建与编辑
- 🔔 智能提醒
- 📬 节日/天气订阅
- 🔗 与 Roamio 旅行计划联动

### 技术栈
- **Android 原生**: Kotlin + Jetpack Compose
- **后端**: Django REST Framework（独立项目）
- **数据库**: SQLite / MySQL

### 与 Roamio 的联动
1. **旅行计划 → 日历事件**
   - 用户在 Roamio 创建旅行计划
   - 自动在 Ralendar 生成对应日程
   - 提前提醒准备事项

2. **日历订阅 → 旅行灵感**
   - 用户在 Ralendar 订阅"樱花季"
   - Roamio 推送相关旅行攻略

3. **打卡记录 → 时间轴**
   - Roamio 的打卡自动标记到 Ralendar
   - 生成完整的旅行时间轴

### 当前状态
- 🔄 独立开发中
- 🔄 等待 QQ 授权通过后融合

## 📝 子产品 2：Rote

### 定位
**笔记工具** - Roamio 生态的内容创作工具

### 核心功能
- 📔 Markdown 笔记编辑
- 🗂️ 笔记本分类管理
- 🏷️ 标签系统
- 🔗 与 Roamio 旅行关联
- 📤 一键发布到 Roamio

### 使用场景
- 旅行前：攻略整理、行程规划
- 旅行中：游记撰写、感想记录
- 旅行后：经验总结、回忆整理

### 与 Roamio 的联动
1. **笔记 → 旅行计划**
   - 在 Rote 整理攻略
   - 一键转为 Roamio 旅行计划

2. **旅行 → 笔记**
   - Roamio 旅行结束后
   - 自动生成笔记模板

### 当前状态
- 📋 规划中
- 📋 等待 Ralendar 完成后启动

## 📸 子产品 3：Rapture

### 定位
**照片管理** - Roamio 生态的视觉记忆库

### 核心功能
- 📷 照片智能分类（AI）
- 🗺️ 地理位置标记
- 📅 时间轴展示
- 🎨 滤镜与编辑
- 🔗 与 Roamio 旅行关联

### 使用场景
- 旅行照片自动按地点分类
- 生成精美的旅行相册
- 一键分享到 Roamio

### 与 Roamio 的联动
1. **照片 → 旅行记录**
   - 上传照片自动识别地点
   - 关联到对应的旅行

2. **旅行 → 相册**
   - Roamio 旅行自动生成相册
   - 按时间/地点智能整理

### 当前状态
- 📋 规划中
- 📋 长期规划
