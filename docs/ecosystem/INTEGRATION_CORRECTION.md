## 🎯 为什么是编辑界面？

### 1. 用户场景

**编辑旅行时添加事项** ⭐⭐⭐
```
用户创建/编辑旅行计划
    ↓
填写基本信息、行程安排
    ↓
同时添加待办事项
    ↓
一次性完成旅行规划
```

**查看旅行时添加事项** ⭐
```
用户查看已发布的旅行
    ↓
想添加事项
    ↓
需要先进入编辑模式
    ↓
不够直观
```

### 2. 功能定位

- ✅ 编辑界面：**规划阶段**，适合添加事项
- ❌ 详情页：**展示阶段**，主要用于浏览

### 3. 权限控制

- ✅ 编辑界面：只有作者可以访问，权限明确
- ❌ 详情页：所有人都可以访问，需要复杂的权限判断

## 🎯 使用流程

### 创建新旅行

1. 点击"创建旅行"
2. 填写基本信息
3. 点击"保存"（此时生成 tripId）
4. **事项管理栏出现**
5. 可以开始添加事项

### 编辑现有旅行

1. 进入旅行编辑界面
2. **事项管理栏已显示**
3. 可以直接添加/编辑事项
