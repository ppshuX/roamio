# 🚀 Roamio v2.0 实施优先级指南

> **目的**: 为 Cursor AI 提供清晰的开发顺序，确保高效推进  
> **原则**: 先核心后扩展，先独立后融合，先功能后优化

---

## 📊 优先级分级

| 级别 | 说明 | 时间要求 |
|------|------|---------|
| **P0** | 核心功能，必须完成 | 立即开始 |
| **P1** | 重要功能，尽快完成 | 1-2 周内 |
| **P2** | 增强功能，可延后 | 2-4 周内 |
| **P3** | 优化功能，按需实施 | 4 周后 |

#### 1.1 数据库模型（预计 1 天）

**任务**：创建 `TripEvent` 模型

```bash
# 执行步骤
1. 创建 trips/models/event.py
2. 在 trips/models/__init__.py 中导入
3. 运行 python manage.py makemigrations
4. 运行 python manage.py migrate
```

**验收标准**：
- ✅ 数据库表创建成功
- ✅ 包含所有必需字段（title, trip, user, location, reminder 等）
- ✅ 索引创建正确

#### 1.2 基础 API（预计 2 天）

**任务**：实现事件 CRUD API

```bash
# 执行步骤
1. 创建 trips/serializers/event_serializer.py
2. 创建 trips/api/viewsets/event_viewset.py
3. 在 trips/urls/api_urls.py 中注册路由
4. 测试 API（使用 Postman 或 curl）
```

**API 端点**：
- `GET /api/v1/trips/{trip_id}/events/` - 获取事件列表
- `POST /api/v1/trips/{trip_id}/events/` - 创建事件
- `GET /api/v1/trips/{trip_id}/events/{id}/` - 获取事件详情
- `PUT /api/v1/trips/{trip_id}/events/{id}/` - 更新事件
- `DELETE /api/v1/trips/{trip_id}/events/{id}/` - 删除事件

**验收标准**：
- ✅ 所有 CRUD 操作正常
- ✅ 权限控制正确（只能操作自己的事件）
- ✅ 返回格式符合规范

## 🚦 决策点

### 决策 1: 是否等待 Ralendar 完成？

**选项 A**：等待 Ralendar 完成事件 API 后再开发同步功能  
**选项 B**：先完成 Roamio 端功能，预留接口，后续对接

**推荐**：✅ **选项 B**

**理由**：
- Roamio 可以独立运行，不依赖 Ralendar
- 用户可以先使用基础功能
- 后续对接更灵活

### 决策 2: 地图选择百度还是高德？

**选项 A**：百度地图（文档中推荐）  
**选项 B**：高德地图

**推荐**：✅ **选项 A（百度地图）**

**理由**：
- 免费配额更高（展示 5w/天 vs 高德 3w/天）
- 文档更完善
- 国内覆盖更好

### 决策 3: 提醒功能自己实现还是用 Ralendar？

**选项 A**：Roamio 自己实现（Celery + Redis）  
**选项 B**：调用 Ralendar 的提醒服务

**推荐**：✅ **选项 B（调用 Ralendar）**

**理由**：
- 避免重复开发
- Ralendar 是专业的日历提醒系统
- 统一提醒管理更方便

## 💡 给 Cursor AI 的建议

### 开发顺序

1. **先做能看到的**：从前端组件开始，用户能直观感受到进展
2. **先做能用的**：优先实现核心功能，增强功能可以后续迭代
3. **先做独立的**：不依赖 Ralendar 的功能先做，避免被阻塞

### 代码风格

- 保持与现有代码风格一致
- 使用 Vue 3 Composition API
- 组件拆分合理，单一职责
- 变量命名清晰，见名知意

### 测试建议

- 每完成一个功能立即测试
- 使用浏览器开发者工具调试
- 测试边界情况（空数据、网络错误等）

### 文档建议

- 新增 API 立即更新文档
- 复杂逻辑添加注释
- 用户可见功能更新使用说明
