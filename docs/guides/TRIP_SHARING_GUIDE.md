# 旅行页面分享指南

## 📋 URL格式说明

### ✅ 正确的分享链接格式（History模式）

当前项目使用 **Vue Router History模式**，URL格式应该是：

```
https://roamio.cn/trip/{slug}/
```

**示例：**
```
https://roamio.cn/trip/a1b2c3d4e5f6/
```

### ❌ 错误的URL格式

**不要使用带 `#` 的URL：**
```
❌ https://roamio.cn/#/trip/a1b2c3d4e5f6/
```

这种格式**不会工作**，因为项目使用的是History模式，不是Hash模式。

## 🔧 路由配置说明

### 前端路由（Vue Router）

```javascript
// web/src/router/index.js
const router = createRouter({
  history: createWebHistory(),  // ✅ History模式（无#）
  routes
})
```

### 后端路由（Django）

```python
# roamio/urls.py
# Catch-all：匹配所有非API路径，返回Vue应用
re_path(r'^(?!admin|api|static|media|trips|accounts).*$', views.vue_app)
```

这意味着所有路径（如 `/trip/a1b2c3d4e5f6/`）都会被Django捕获，返回Vue的`index.html`，然后由Vue Router在客户端处理路由。

## 🔗 如何获取分享链接

### 方法1：从浏览器地址栏复制

1. 创建旅行并设置为**公开**
2. 点击"查看"进入旅行详情页
3. 浏览器地址栏显示：`https://roamio.cn/trip/a1b2c3d4e5f6/`
4. 直接复制这个URL即可分享

### 方法2：在"我的旅行"页面查看

在"我的旅行"列表中，每个旅行都有一个"查看"按钮，点击后URL就是分享链接。

## ✅ 访问权限说明

### 公开旅行（visibility = 'public'）

- ✅ **所有人可以访问**（无需登录）
- ✅ **直接通过链接访问**
- ✅ **可以分享给任何人**
- ✅ **可以在首页旅行列表中显示**

### 私有旅行（visibility = 'private'）

- ✅ **作者本人可以访问**（需要登录）
- ❌ **其他人无法访问**（返回404）
- ❌ **不会出现在公开列表中**

## 🎯 分享步骤

1. **创建旅行计划**
   - 访问 `/editor/new/`
   - 填写旅行信息
   - 在右侧"设置"面板中，将"可见性"设置为**"公开"**

2. **保存并发布**
   - 点击"保存"按钮
   - 将"状态"设置为"已发布"（可选）

3. **获取分享链接**
   - 点击"查看"按钮
   - 复制浏览器地址栏中的URL
   - 格式：`https://roamio.cn/trip/{slug}/`

4. **分享链接**
   - 通过微信、QQ、邮件等分享
   - 接收者可以直接点击链接访问
   - 无需注册或登录（如果设置为公开）

---

## 📝 注意事项

1. **URL中没有 `#`**
   - 当前项目使用History模式，URL格式为：`/trip/slug/`
   - 如果看到带 `#` 的URL，是**错误的**

2. **必须设置为"公开"**
   - 只有"公开"的旅行才能被所有人访问
   - "私有"旅行只能作者本人访问

3. **直接访问会工作**
   - 即使刷新页面也不会丢失路由
   - 因为Django的catch-all路由会处理所有路径
   - Vue Router会在客户端接管路由

4. **链接格式固定**
   - 所有旅行都使用相同的URL格式
   - 只有`slug`部分不同
   - Slug是自动生成的12位哈希值

## 💡 常见问题

### Q: 为什么我的链接不工作？

**A:** 可能的原因：
1. 旅行设置为"私有" - 改为"公开"
2. URL格式错误（有`#`） - 去掉`#`
3. 服务器未部署最新代码 - 检查部署

### Q: 可以自定义URL吗？

**A:** 当前不支持，slug是自动生成的哈希值，确保唯一性。

### Q: 链接会被搜索引擎索引吗？

**A:** 如果旅行设置为"公开"，搜索引擎可以索引。建议添加适当的meta标签和SEO优化。
