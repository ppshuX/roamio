# 📱 支付宝开放平台配置步骤（详细版）

> **针对 Roamio 项目的支付宝配置**

---

## 🎯 当前步骤

你现在在：**支付宝开放平台 → 应用 → 开发设置**

这是正确的位置！✅

---

## 📋 必需配置（第一步）

### ⭐ 接口加签方式（必须配置！）

**这是最重要的配置，没有这个无法调用支付接口。**

#### 步骤：

1. 找到 **"接口加签方式 (密钥/证书)"**
2. 点击右侧的 **"设置"** 按钮
3. 选择配置方式：
   - **推荐**：选择 **"密钥"** 方式
   - 密钥类型：选择 **"RSA2"**（更安全）
4. 生成密钥：
   - 选择 **"自动生成密钥"**（最简单）
   - 或者上传你自己的密钥对
5. 保存配置

#### 配置完成后，你会得到：

1. **应用ID（app_id）**
   - 在页面顶部可以看到
   - 例如：`2021006108629563`
   - ✅ 这个已经显示在你页面上了

2. **应用私钥（private_key）**
   - 保存这个，后续在 Ping++ 需要用到
   - ⚠️ **重要**：请妥善保存，不要泄露

3. **支付宝公钥（public_key）**
   - 支付宝提供的公钥
   - 在密钥管理页面可以看到
   - ✅ 后续在 Ping++ 也需要用到

---

## ✅ 可选配置（可以跳过）

以下配置对于**基础支付功能**不是必需的：

### 1. 接口内容加密方式
- ❌ **可以不配置**
- 只有需要获取用户手机号等敏感信息时才需要
- 支付功能不需要

### 2. 服务器IP白名单
- ❌ **开发阶段可以不配置**
- 用于限制接口调用来源IP
- 如果配置了，需要添加你的服务器IP

### 3. 应用网关
- ❌ **可以不配置**
- Ping++ 会处理支付回调
- 除非你需要直接接收支付宝回调

### 4. 授权回调地址
- ❌ **可以不配置**
- 只有需要用户授权时才需要（如获取用户信息）
- 支付功能不需要

---

## 🔑 获取密钥信息

配置完成后，获取密钥：

1. **查看应用ID（app_id）**
   - ✅ 在页面顶部：`2021006108629563`

2. **查看私钥和公钥**
   - 方法1：在"接口加签方式"设置页面查看
   - 方法2：在"应用详情" → "密钥管理"中查看

3. **复制私钥**
   - 格式通常是：
     ```
     -----BEGIN RSA PRIVATE KEY-----
     ...（长串字符）...
     -----END RSA PRIVATE KEY-----
     ```

4. **复制支付宝公钥**
   - 格式通常是：
     ```
     -----BEGIN PUBLIC KEY-----
     ...（长串字符）...
     -----END PUBLIC KEY-----
     ```

---

## 📝 下一步：配置 Ping++

配置完支付宝密钥后，下一步：

1. 打开 Ping++ 控制台
2. 找到 **"支付宝电脑网站支付"**
3. 点击 **"填写参数"**
4. 填入：
   ```
   app_id：2021006108629563
   private_key：（从支付宝开发设置复制）
   public_key：（从支付宝开发设置复制）
   ```
5. 同样配置 **"支付宝手机网站支付"**（使用相同参数）

## ⚠️ 注意事项

1. **私钥安全**
   - ⚠️ 不要泄露私钥
   - ⚠️ 不要提交到 Git
   - ✅ 应该保存在环境变量中

2. **测试环境**
   - ✅ 建议先在测试环境配置和测试
   - ✅ 确认无误后再切换到生产环境

3. **应用状态**
   - 如果应用状态是"开发中"，只能用于测试
   - 需要上线时，需要提交审核
