# 📱 Ping++ 支付配置指南

> **针对 Roamio Web 应用的 Ping++ 配置**

---

## 🎯 推荐配置的支付渠道

对于 Roamio 这个 **Web 应用**，推荐配置以下支付渠道：

1. **支付宝电脑网站支付**（PC）
   - 适合：桌面浏览器用户
   - 场景：用户在电脑上访问网站支付

2. **支付宝手机网站支付**（WAP）
   - 适合：移动浏览器用户（手机访问网站）
   - 场景：用户在手机上访问网站支付

3. **微信 H5 支付**（WAP）
   - 适合：移动浏览器用户（手机访问网站）
   - 场景：用户在手机上访问网站支付

## ⚠️ 重要提示：企业认证问题

**个人开发者注意**：
- Ping++ 配置支付渠道需要先完成**企业信息审核**
- 如果没有企业资质，可以：
  1. ✅ **先使用模拟支付**（推荐）：代码已支持，无需配置任何支付渠道
  2. 📞 **联系 Ping++ 客服**：询问个人开发者如何认证
  3. 📝 **尝试填写个人信息**：将个人信息填写到企业信息表单（可能不被接受）

**建议**：如果是学习项目，先使用模拟支付测试完整流程，后续有需要再配置真实支付。

## 📋 配置步骤

### 第零步：企业信息认证（如需配置真实支付）

如果 Ping++ 要求完成企业信息审核，你需要：

#### 对于个人开发者：
1. **公司名称**：填写你的真实姓名（如：吕文潇）
2. **注册地址**：填写你的实际地址
3. **行业细分**：选择"工具软件" → "其他工具"
4. **联系地址**：填写你的实际地址
5. **营业执照**：❌ 个人开发者没有营业执照
   - 可以尝试上传身份证（可能不被接受）
   - 或联系 Ping++ 客服询问个人开发者认证方式

**注意**：如果企业信息审核被拒绝，可以：
- 联系 Ping++ 客服说明是个人开发者
- 或直接使用模拟支付功能（推荐）

---

### 第一步：在支付宝开放平台配置密钥（如需要配置真实支付）

你现在在正确的位置！**支付宝开放平台 → 开发设置**

#### 1.1 配置接口加签方式（最重要！）

1. 找到 **"接口加签方式 (密钥/证书)"**，点击 **"设置"** 按钮
2. 选择 **"密钥"** 方式（推荐）
3. 选择 **"RSA2"** 密钥类型
4. 系统会自动生成密钥对，或你可以上传自己的密钥
5. 保存后，你会得到：
   - `app_id`：应用ID（如：2021006108629563）
   - `private_key`：应用私钥（用于签名）
   - `public_key`：支付宝公钥（支付宝提供，用于验证）

**重要**：
- ✅ 这个配置是**必需的**，否则无法调用支付宝支付接口
- ✅ 保存好 `private_key` 和 `public_key`，后续在 Ping++ 需要用到
- ✅ `app_id` 在页面顶部可以看到（如：2021006108629563）

#### 1.2 其他配置（可选）

**暂时可以不配置**：
- ❌ 接口内容加密方式（可选，支付不需要）
- ❌ 服务器IP白名单（可选，开发阶段可以不设置）
- ❌ 应用网关（可选，Ping++ 会处理回调）
- ❌ 授权回调地址（可选，除非需要用户授权）

**注意**：如果后续需要获取用户信息等功能，才需要配置这些。

### 第二步：在 Ping++ 控制台配置支付渠道

1. 回到 Ping++ 控制台（https://dashboard.pingxx.com）
2. 找到 **"支付宝电脑网站支付"**，点击 **"填写参数"**
3. 填写以下信息（从上一步获取）：

```
app_id：2021006108629563（你的应用ID）
private_key：你的应用私钥（从开发设置获取）
public_key：支付宝公钥（从开发设置获取）
partner_id：（可选，通常是支付宝PID，如果没有可以留空）
```

4. 同样配置 **"支付宝手机网站支付"**（使用相同的参数）

---

### 第二步：配置支付宝手机网站支付

1. 在 Ping++ 控制台，找到 **"支付宝手机网站支付"** 行
2. 点击右侧的 **"填写参数"** 按钮
3. 填写参数（与支付宝电脑网站支付相同）：
   - 使用同一个支付宝应用
   - `app_id`、`private_key`、`public_key` 都相同

---

### 第三步：配置微信 H5 支付

1. 在 Ping++ 控制台，找到 **"微信 H5 支付"** 行
2. 点击右侧的 **"填写参数"** 按钮
3. 填写以下信息：

```
渠道类型：微信 H5 支付（wx_pub_qr）

必填参数：
- app_id：微信应用 ID（从微信商户平台获取）
- mch_id：微信商户号
- key：微信支付密钥
- app_secret：微信应用密钥（可选，用于获取用户信息）
```

**如何获取这些参数**：
- 访问：https://pay.weixin.qq.com/
- 登录微信支付商户平台
- 在账户中心查看 `mch_id`（商户号）
- 在 API 安全中设置支付密钥 `key`
- 如果是服务号，在微信公众平台获取 `app_id` 和 `app_secret`

---

### 第四步：获取 Ping++ API Key

1. 在 Ping++ 控制台，点击 **"应用设置"** → **"API Keys"**
2. 查看 **"Live Key"**（生产环境）和 **"Test Key"**（测试环境）
3. 复制 **Test Key**（开发阶段使用）

---

### 第五步：配置 Roamio 项目

#### 5.1 安装 Ping++ Python SDK（可选）

Ping++ 支持直接调用 REST API，也可以使用 SDK。我们使用 REST API（更灵活）。

如果需要 SDK：

```bash
pip install pingpp
```

#### 5.2 配置环境变量

在 `.env` 文件中添加：

```env
# Ping++ 配置
PINGPP_API_KEY=你的Test Key（测试环境）
PINGPP_APP_ID=app_1unjXLmPCCeL90q9（你的应用ID）
PINGPP_USE_TEST=True（测试环境）
PINGPP_CALLBACK_URL=https://你的域名/api/payment/pingpp/callback/
```

**说明**：
- `PINGPP_API_KEY`：从 Ping++ 控制台获取的 Test Key
- `PINGPP_APP_ID`：从控制台左侧可以看到（如 `app_1unjXLmPCCeL90q9`）
- `PINGPP_USE_TEST`：测试环境设置为 `True`，生产环境设置为 `False`
- `PINGPP_CALLBACK_URL`：支付回调 URL（需要是公网可访问的地址）

## 📝 配置注意事项

### 1. 支付宝配置

**个人开发者限制**：
- 个人开发者可以申请支付宝开放平台账号
- 需要实名认证
- 可能需要提供身份证、银行卡等信息

**参数说明**：
- `app_id`：支付宝应用 ID（10 位数字）
- `private_key`：RSA2 私钥（用于签名）
- `public_key`：RSA2 公钥（支付宝提供）

### 2. 微信配置

**个人开发者限制**：
- 微信支付需要企业认证
- 个人开发者可能需要使用其他方式（如微信收款码）
- 或者先配置支付宝，微信后续添加

**参数说明**：
- `app_id`：微信应用 ID（服务号/小程序）
- `mch_id`：微信商户号（10 位数字）
- `key`：支付密钥（32 位字符串）

## 🚀 生产环境切换

当准备上线时：

1. **切换到生产环境**：
   ```env
   PINGPP_USE_TEST=False
   PINGPP_API_KEY=你的Live Key（生产环境）
   ```

2. **配置生产环境回调 URL**：
   ```env
   PINGPP_CALLBACK_URL=https://你的正式域名/api/payment/pingpp/callback/
   ```

3. **在 Ping++ 控制台配置 Webhook**：
   - 应用设置 → webhooks
   - 添加回调 URL
   - Ping++ 会向这个 URL 发送支付结果通知

## ⚠️ 常见问题

### Q1: 个人开发者可以申请支付宝/微信支付吗？

**A**: 
- **支付宝**：✅ 可以，个人开发者可以申请支付宝开放平台账号
- **微信支付**：❌ 需要企业认证，个人开发者通常无法申请

**建议**：
- 先配置支付宝（个人开发者可用）
- 微信支付可以后续添加，或使用其他方式

### Q2: 不想配置支付渠道，可以测试吗？

**A**: ✅ 可以！
- 代码已经支持模拟支付
- 不需要配置任何支付渠道
- 可以直接测试完整流程

### Q3: 支付宝参数从哪里获取？

**A**: 
1. 访问 https://open.alipay.com/
2. 登录支付宝开放平台
3. 创建"网站应用"
4. 在应用详情获取 `app_id`
5. 在"密钥管理"中配置 RSA2 密钥，获取公私钥

### Q4: 回调 URL 必须公网可访问吗？

**A**: 
- ✅ 是的，Ping++ 需要向你的服务器发送回调通知
- 开发阶段可以使用内网穿透工具（如 ngrok）
- 生产环境使用正式域名
